# Önceden mevcut sentetik kaynaklar

**Demonstration only — No real system assessed.**

Yeni bir assessment/fixture üretilmez veya burada kopyalanmaz. Birinci komutta açıkça seçilen kaynaklar korunmuş [Phase14 assessment.json](../../../docs/commercial/examples/assessment.json) ve ayrı [manifest.json](../../../docs/commercial/examples/manifest.json) dosyalarıdır. Kaynak/provenance geçmişi [mevcut örnek rehberindedir](../../../docs/commercial/examples/README.tr.md).

Assessment: 3907 byte, SHA256 `c3104e05c372eab172f2247ae748d867b5e5e01d2adf4daa40d21e5515267ab9`; `venom-rendered-assessment/v1`, `web-review`, `complete`, bir subject ve dört informational/observation item. Manifest: 711 byte, SHA256 `c77ce74508e8efaff7ebf1b0203331b4295d468c726e4acd7bad709eb85813df`; yalnız seçilmiş JSON-entry ve özet ilişkisinin ölçülmesine uygundur. Bildirilen HTML okunmaz, tam bundle doğrulanmaz.

Phase15'in [gözlem defteri](../../../docs/commercial/operations/examples/DEMO_OBSERVATION_LEDGER.md) aynı dört fingerprint ile `/items/0..3` konumunu ve yapılmamış insan incelemesini kaydeder. Bu Markdown parse edilmez veya değiştirilmez; gerçek native JSON'dan aktarım yapılır.

A birincil assessment ve kısmi manifesttir. C bağımsız comparison, D ise elle yazılmış Phase11 incomplete diagnostic örneğidir. C ve D yeni bridge girdisine veya aynı koşuya eklenmez. Comparison retest; diagnostic native CLI çıktısı olarak sunulmaz.

Gerçek komut, üretilen üç intake + dört handoff dosyası ve gözlem/NOT_RUN ayrımı [Phase17 entegrasyon notunda](../../../docs/commercial/operations/phase17/DEMO_INTEGRATION.tr.md) verilir. Kaynak veya çıktının mevcut olması gerçek müşteri, yetki, uzman veya teslim onayı üretmez.
