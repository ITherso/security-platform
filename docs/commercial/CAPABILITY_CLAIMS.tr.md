# Kaynak destekli yetenek ve iddia envanteri

Bu envanter, `ITherso/termivar` **6a2639348c2366d0bf71b9a34e5484d40aa393a3** checkout'unun salt okunur incelemesidir. Workspace sürümü `0.10.0-alpha.3`; yayımlanmış alpha.2 binary'si, eski örnekleri üreten development binary'si ve bu kaynak aynı kimlik değildir. Bu fazda hiçbir Termivar komutu, build, test veya hedef değerlendirmesi çalıştırılmadı. “Kaynakta mevcut” çalıştırılabilir kod yolunu belirtir; seçilecek executable'ın özellikleri veya production güvenilirliği için kabul sonucu değildir.

Üç sınıf: **M — kaynakta mevcut**, **K — kısmen mevcut/kısıtlı**, **Y — planlanan veya mevcut üründe bulunmayan**. M sınıfı bile pilot öncesi build/özellik ve işletim kabulünü gerektirir. Kaynak [experimental / not production-ready](https://github.com/ITherso/termivar/blob/6a2639348c2366d0bf71b9a34e5484d40aa393a3/README.md#L16-L20) olarak tanımlanır; bağımsız audit tamamlanmış değildir. `capabilities` çıktısı da binary'nin resmî release kökenini kanıtlamaz.

### Gerçek teknik limitler

| Boyut | `baseline` | Temel `web-review` varsayılanı |
|---|---:|---:|
| Kapsam/subject | Single resource / 1 | Exact-origin / en fazla 64 subject |
| Discovery depth / belge başına references | 0 / 0 | 2 / 128 |
| Paylaşılan broker toplam request | 16 | 256 |
| Wall-time sınırı | 60.000 ms | 300.000 ms |
| Kümülatif response byte | 1 MiB | 16 MiB |
| Bir response body retention | Varsayılan 256 KiB | 256 KiB |
| Temel active-verification limit | 4 | 10 |
| Çalışma concurrency | 1 | 1 |

Baseline kaynakları: [scan_profile.rs23–27](https://github.com/ITherso/termivar/blob/6a2639348c2366d0bf71b9a34e5484d40aa393a3/crates/termivar-scanner/src/web_runtime/scan_profile.rs#L23-L27), [baseline_web_assessment_limits450–467](https://github.com/ITherso/termivar/blob/6a2639348c2366d0bf71b9a34e5484d40aa393a3/crates/termivar-scanner/src/web_runtime/scan_profile.rs#L450-L467), [runtime active default](https://github.com/ITherso/termivar/blob/6a2639348c2366d0bf71b9a34e5484d40aa393a3/crates/termivar-scanner/src/runtime_budget.rs#L34). Web-review limitlerinin bağlanması `ScanProfileV1::web_review` ve yukarıdaki `Default` yolundadır. **10, bütün optional feature kombinasyonlarının mutlak active tavanı değildir**: [optional_active_verifications2929 ve devamı](https://github.com/ITherso/termivar/blob/6a2639348c2366d0bf71b9a34e5484d40aa393a3/crates/termivar-scanner/src/web_runtime/web_assessment.rs#L2929-L2984) açık seçilen child allowance'larını ekler. Tek sayaç, provider/IdP dahil bütün ağ faaliyetlerinin veya başarılı cevapların sayısı diye sunulmaz.

Library seviyesinde doğrulanan hard cap örnekleri 1.024 subject, depth16, 10.000 broker request, toplam256 MiB, 3.600 saniye ve active64'tür; bunlar ilk pilotun çalışma limitleri veya CLI'dan açılabilen override'lar değildir. CLI [yalnız profil enumu seçer](https://github.com/ITherso/termivar/blob/6a2639348c2366d0bf71b9a34e5484d40aa393a3/crates/termivar-cli/src/main.rs#L690-L704). Pilot seçim/durdurma kayıtları [PILOT_SCOPE](PILOT_SCOPE.tr.md) içindedir.

## Kaynakta kayıtlı komut biçimleri

Aşağıdaki komutlar **çalıştırılmamış söz dizimi örnekleridir**; hedefe gitme veya dosya üretme talimatı/izni değildir. Angle-bracket değerleri placeholder'dır; gerçek credential burada yer almaz.

```text
termivar capabilities --format json
termivar scan <AUTHORIZED_TARGET> --profile baseline --format json
termivar scan <AUTHORIZED_TARGET> --profile web-review --report-format json
termivar scan <AUTHORIZED_TARGET> --profile web-review --report-dir <NEW_OUTPUT_DIRECTORY>
termivar report compare --before <COMPLETE_BEFORE_JSON> --after <COMPLETE_AFTER_JSON> --same-scope --format json
termivar report verify --dir <COMPLETE_THREE_FILE_BUNDLE> --format json
```

`scan` profilesiz yolu `decision-scan/v1` operasyonel karar/outcome çıktısıdır; müşteri findings raporu diye kullanılmaz. `baseline` typed assessment renderer'ı kullanmaz. `--report-dir`, `--report-format` ve `--report-output` birlikte keyfî kullanılamaz; kaynak validation çakışmaları reddeder. Report Compare Markdown/JSON/HTML; Verify text/JSON çıktıları kaynakta vardır. Seçilen binary'nin tam komut ve özellik desteği, ayrı gelecekteki yerel kabulde kaydedilmelidir. Bu fazın gerçek faaliyeti dosya/kaynak okuma, belge hazırlığı ve byte/SHA256 paketleme ölçümüdür.
